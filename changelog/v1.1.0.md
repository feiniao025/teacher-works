班主任平台 v1.1.0 —— 全新「AI 试卷批改（多模态）」正式发布。

在 v1.0.x 稳定的班级事务管理基础上，本版新增 AI 试卷批改能力：老师上传试卷图片，AI 自动逐题批改、给分并生成总评，可一键采纳录入成绩。功能默认不启用，需在设置中开启并配置模型供应商，对既有功能与数据库结构零影响。

## 本版新增

- **AI 试卷批改（多模态）**：上传试卷照片 / 扫描件，AI 逐题判分、标注对错、生成整体评语；批改结果可一键采纳进成绩册，或导出留档
- **多供应商可配置切换**：兼容 OpenAI 接口的任意服务——云端（DeepSeek / OpenAI 等）或本地（LM Studio / Ollama / vLLM），可保存多套配置、随时切换、一键连通性测试
- **流式响应 + 实时进度**：批改时实时显示「模型思考中…已生成 N 字」，慢速本地推理模型批改整卷也不会被误判超时
- **思考模式与「思考失控保护」**：可开启「抑制思考」——对支持的模型尽力关闭思考过程；对所有模型启用失控保护，思考超过设定上限仍未作答即提前中止，避免长时间空转
- **灵活的 Token 策略**：可关闭「限制 Tokens」，让推理型模型按自身上下文上限自由生成（思考过程也占用额度，限制过小会导致答案被截断）
- **返回结果多级容错**：模型输出的 JSON 出现缺逗号、多余尾逗号或轻微残缺时自动修复 / 打捞，尽量避免整单批改失败
- **传输层稳健化**：底层改用 http/https 直连，规避慢速模型长等待被客户端默认超时误杀（表现为「fetch failed」）

## 本版修复

- `start.sh` 在 Apple Silicon 下统一以 arm64 承载 node/npm，修复 PATH 中为 x64-only node 时启动报「Bad CPU type」的问题

## 快速开始

**Windows**：解压 zip → 双击 `install.bat` → 双击 `start.bat` → 访问 http://localhost:3000（admin / admin123）

**Linux / macOS**：`tar -xzf *.tar.gz && cd teacher-ops && ./start.sh`

**Docker**：解压后执行 `./deploy.sh`，或改用上面的 GHCR 镜像

## 启用 AI 批改

1. 进入「AI 批改」设置，开启功能开关
2. 新建供应商：填写服务地址（OpenAI 兼容 base_url，本地服务通常以 `/v1` 结尾，遗漏时系统会自动兜底）、模型名、可选 API Key
3. 本地 / 推理型模型建议：开启「流式响应」、关闭「限制 Tokens」、按需开启「思考模式」
4. 点「测试连接」确认可用后，上传试卷图片即可批改

> 隐私提示：试卷图片会发送到你配置的模型服务。使用本地模型（LM Studio / Ollama 等）时数据不出本机；使用云端服务时将经由对应厂商，请按所在机构的合规要求选择。

## 升级与兼容性

- 数据库结构与既有业务逻辑无破坏性变更，从 v1.0.x 升级**无需数据迁移**：解压新代码覆盖 → `docker compose restart`（或 `./stop.sh && ./start.sh`）
- AI 批改为**可选功能，默认不启用**；不配置则完全不影响原有使用
- 三种既有部署方式（源码 / Docker 本地构建 / Windows 批处理）均不受影响

完整变更见 [v1.0.1...v1.1.0 提交对比](https://github.com/kyhx1984/teacher-works/compare/v1.0.1...v1.1.0)。
